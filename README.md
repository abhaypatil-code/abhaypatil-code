**Production RAG System & Conversational AI Agent**

- *Tech:* Python, LangChain, FAISS, OpenAI API, Streamlit

### ⚖️ [SpecterSummarizer](https://github.com/abhayshantesh/SpecterSummarizer)
**Legal Judgment Summarization — Fine-tuned LLM**

- Applied **Optuna** hyperparameter optimization and mixed-precision (FP16) training for GPU efficiency
- *Tech:* Python, PyTorch, T5, Hugging Face, Optuna, NLP

- Designed for rural healthcare workers enabling preventive care before symptom onset
- *Tech:* Python, scikit-learn, Pandas, NumPy, Flask

### 🚀 [NASA-Turbojet-BigData-Analysis](https://github.com/abhayshantesh/NASA-Turbojet-BigData-Analysis-HDFS-Hive)
